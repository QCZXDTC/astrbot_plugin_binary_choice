# 二选一自动回答插件 (astrbot_plugin_binary_choice)

一个用于 AstrBot 的趣味互动插件：自动识别群聊中的"二选一"问题，并通过大模型判断后随机给出一个建议选项。

---

## ✨ 功能特点

- **智能识别**：自动检测群消息中的"还是"、"或者"、"or"等关键词
- **LLM 判断**：调用大模型智能判断是否为真正的二选一问题，避免误触发
- **随机建议**：从两个选项中随机选择一个，给出"建议您选择：xx"的回复
- **WebUI 配置**：支持在 AstrBot 管理面板中可视化调节所有参数
- **防刷屏机制**：内置冷却时间，防止同一用户频繁触发
- **黑白名单**：支持按群号设置生效范围
- **防自触发**：可配置机器人 QQ 号，避免回复自己

---

## 📦 安装方法

1. 下载本插件文件夹 `astrbot_plugin_binary_choice`
2. 将整个文件夹放入 AstrBot 的插件目录：
   ```
   AstrBot/data/plugins/astrbot_plugin_binary_choice/
   ```
3. 重启 AstrBot 或点击 WebUI 重载插件
4. 在 WebUI → 插件管理 → 找到本插件 → 点击启用并配置

## ⚙️ 配置说明

在 AstrBot WebUI 的插件配置页面，可以对以下参数进行调节：

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `enable` | bool | `true` | 是否启用插件 |
| `keywords` | list | `["还是", "或者", "or"]` | 触发关键词列表，消息中包含任意一个即进入判断流程 |
| `reply_template` | string | `建议您选择：{choice}` | 回复模板，`{choice}` 会被替换为随机选择的选项 |
| `reply_interval` | int | `30` | 同一用户的回复冷却时间（秒），范围 1~3600 |
| `bot_qq` | string | 空 | 机器人 QQ 号，填写后不会回复自己发的消息 |
| `blacklist_groups` | list | `[]` | 黑名单群号列表，列表中的群不会触发本插件 |
| `whitelist_groups` | list | `[]` | 白名单群号列表，留空则所有群生效 |

## 🔧 工作原理

1. **消息监听**：监听群内所有消息
2. **关键词过滤**：检查消息是否包含配置的关键词
3. **LLM 判断**：调用大模型判断该消息是否为真正的二选一问题
4. **选项提取**：如果是，大模型提取出两个选项
5. **随机选择**：从两个选项中随机选取一个
6. **回复发送**：按照配置的模板格式发送回复

## ❓ 常见问题

### Q：插件没有反应？
A：请检查以下几点：
- 插件是否在 WebUI 中已启用
- AstrBot 是否已配置并启用大模型
- 消息中是否包含配置的关键词
- 当前群是否在白名单中（如果设置了白名单）

### Q：回复太频繁怎么办？
A：调大 `reply_interval` 参数，增大同一用户的冷却时间。

### Q：想让机器人不回复自己？
A：在 `bot_qq` 中填写机器人的 QQ 号即可。

### Q：只想在特定群生效？
A：在 `whitelist_groups` 中填入允许生效的群号列表，留空则全部群生效。
